# Agile Project Board - Lab 02

## Scenario Selected
Library Book Search System

## Team Roles & Responsibilities
- **Coordinator:** Manages project backlog, board structure, and item priorities.
- **Developer:** Implements feature code based on user story criteria.
- **Reviewer:** Conducts code reviews and checks workflow updates.
- **Tester:** Validates acceptance criteria and confirms Definition of Done.

## Workflow States
1. **Backlog:** Newly identified user stories and feature requests.
2. **Ready:** Prioritized tasks with clear acceptance criteria.
3. **In Progress:** Tasks currently under development.
4. **Review:** Completed tasks waiting for code/criteria review.
5. **Done:** Verified features satisfying all criteria.

## Definition of Done (DoD)
- Code is complete and follows coding standards.
- All acceptance criteria are fully met and verified.
- Testing is performed without breaking existing features.
- Code/task is reviewed and board status is updated.
